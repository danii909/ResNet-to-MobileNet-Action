Run logs: spiegazione dei file in experiments/logs/.../run-N
===========================================================

Questa guida spiega i file che trovi dentro una cartella run, ad esempio:
experiments/logs/slurm-train-seq-3998/run-1

Idea generale
- I file con estensione (.txt, .json, .csv, .jsonl) contengono dati.
- I file senza estensione (metric_... e status_...) sono marker vuoti:
  servono per leggere subito stato e KPI dal solo nome file con ls.

1) config_summary.json
- Riassunto della configurazione in formato JSON (facile da parsare).
- Include: profile/mode, seed, blocco model, blocco dataset,
  blocco training e blocco distillation.

2) config_summary.txt
- Stesso contenuto di base del JSON ma in formato umano, rapido da leggere.

3) job_meta.txt
- Metadati di esecuzione del run.
- Tipicamente contiene: run_config, started_at, finished_at, exit_code.

4) metrics_epoch.csv
- Storico per epoca in tabella.
- Colonne:
  epoch, train_loss, train_acc, test_loss, test_acc, test_acc_top5, lr, best_acc

5) metrics_epoch.jsonl
- Stesse metriche del CSV, ma una riga JSON per epoca.
- Comodo per script e pipeline di analisi.

6) training_summary.txt
- Riassunto finale del training.
- Tipicamente contiene:
  mode, device, epochs_completed, best_acc, best_epoch,
  final_train_acc, final_test_acc, final_test_top5,
  final_train_loss, final_test_loss, started_at, finished_at, elapsed_seconds,
  path dei file di metriche e config.

7) metric_best_acc_XX.XX
- Marker vuoto: migliore test accuracy raggiunta durante tutto il training.

8) metric_best_epoch_N
- Marker vuoto: epoca (contata da 1) in cui e stata raggiunta best_acc.

9) metric_final_train_acc_XX.XX
- Marker vuoto: train accuracy dell ultima epoca eseguita.

10) metric_final_test_acc_XX.XX
- Marker vuoto: test accuracy dell ultima epoca eseguita.

11) metric_final_test_top5_XX.XX
- Marker vuoto: top-5 accuracy dell ultima epoca eseguita.

12) status_SUCCESS
- Marker vuoto: il run e terminato con exit code 0.

13) status_FAILED
- Marker vuoto: il run e terminato con errore (exit code != 0).
- In un run riuscito non deve esserci.


Top-5 spiegato bene
===================

Che cosa misura
- Per ogni clip/video, il modello produce un punteggio per ogni classe
  (nel tuo caso tipicamente 101 classi).
- Ordina le classi dal punteggio piu alto al piu basso.

Top-1 accuracy
- Conta corretto solo se la classe vera e al primo posto.

Top-5 accuracy
- Conta corretto se la classe vera compare in una qualunque posizione
  tra le prime 5 predizioni.

Formula
- top5 = (numero esempi con classe vera nelle prime 5) / (numero totale esempi) * 100

Esempio semplice
- Classe vera: Diving
- Prime 5 predizioni del modello:
  1) Swimming
  2) CliffDiving
  3) Diving
  4) Surfing
  5) Skijet

Risultato su questo esempio
- Top-1: sbagliato (prima classe non e Diving)
- Top-5: giusto (Diving e comunque nelle prime 5)

Perche top-5 e quasi sempre piu alto di top-1
- E un criterio meno severo: dai al modello 5 tentativi invece di 1.
- Quindi vale sempre: top5 >= top1.

Come leggere i tuoi numeri
- final_test_acc_81.13 = top-1 finale 81.13%
- final_test_top5_96.38 = top-5 finale 96.38%

Interpretazione pratica
- Il modello mette la classe giusta al primo posto in circa 81 clip su 100.
- La mette almeno tra le prime 5 in circa 96 clip su 100.

Quando usare top-5
- Utile su dataset con molte classi simili tra loro.
- Ti dice se il modello e vicino alla risposta corretta anche quando
  sbaglia il primo posto.
